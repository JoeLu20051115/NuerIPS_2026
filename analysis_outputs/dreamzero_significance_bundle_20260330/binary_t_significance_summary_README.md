# Binary + T Significance Summary

Files:
- `binary_t_significance_summary.md`: full DROID + AgiBot significance table.
- `binary_t_significance_compact.md`: compact table without SR values.

Notes:
- The binary success column uses paired exact McNemar p-values.
- The continuous columns use paired t-tests in the better direction: higher is better for Task Progress / L2<0.1 Step Rate, lower is better for Mean L2.
- If you later want the conservative Fisher table instead of paired exact p, it is still kept in `screenshot_sr_count_significance.md`.
