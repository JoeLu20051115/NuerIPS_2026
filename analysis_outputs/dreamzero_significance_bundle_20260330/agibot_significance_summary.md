# AgiBot Significance Summary

Files:
- `agibot_sr_significance_clean.md`: cleaned SR significance table using paired McNemar tests.
- `agibot_paired_t_tests.md`: paired t-test table for Task Progress, Mean L2, and L2<0.1 Step Rate.

Note:
- `F1` is not a standard significance-test statistic; this summary uses McNemar for binary success and paired t-tests for continuous metrics.
- This AgiBot analysis uses the recoverable paired raw currently available in the repo/archive.
