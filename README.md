# π₀.₅ LIBERO-Long Reproduction

This repository reproduces the full and 2,000-step π₀.₅ checkpoints on the ten LIBERO-10 long-horizon tasks, using 50 trials per task and the official OpenPI evaluation semantics.

The implementation and run commands are being built from the approved design:

- [Reproduction design](docs/superpowers/specs/2026-08-01-pi05-libero-long-reproduction-design.md)
- [Implementation plan](docs/superpowers/plans/2026-08-01-pi05-libero-long-reproduction.md)

Large checkpoints, datasets, videos, and logs are intentionally excluded from Git. Their committed SHA-256 manifests make local payloads auditable.
